# ESP32-C3 с печатной IFA-антенной

Проект компактного IoT-устройства на базе микроконтроллера **Espressif ESP32-C3**. Плата оснащена высокоточным датчиком окружающей среды **Bosch BME680** и инвертированной F-антенной (**IFA**). 

## Основные характеристики

*   **Микроконтроллер:** Espressif ESP32-C3 (архитектура RISC-V, Wi-Fi 2.4 ГГц и Bluetooth 5 LE).
*   **RF-тракт:** Интегрированная в топологию платы инвертированная F-антенна (IFA), согласованная с помощью высокодобротных компонентов Murata для стабильной беспроводной связи.
*   **Метео-сенсор:** Датчик **Bosch BME680** для измерения параметров:
    *   Температура воздуха
    *   Относительная влажность
    *   Атмосферное давление
    *   Концентрация летучих органических соединений (VOC / газ) для оценки качества воздуха (IAQ)
*   **Внешняя память:** Внешняя SPI Flash-память объемом 64 Мбит (8 МБ) **Winbond W25Q64JV** 
*   **Интерфейсы и защита:**
    *   Разъем USB Type-C с ESD-защитой
    *   Компактный 3-контактный разъем JST SH (UART)
    *   DIP-переключатели для переключения режимов загрузки и сброса
*   **Питание:** Линейный регулятор (LDO) **Analog Devices ADP7104**
